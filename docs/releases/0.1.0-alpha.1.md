# SA RenderStack v0.1.0-alpha.1

This is the first split-DLL alpha baseline for GTA San Andreas.

## Contents

- x86 Bridge D3D9 proxy at the game root: `d3d9.dll`
- x86 DXVK GTA backend at `backend/dxvk-gta/d3d9.dll`
- Product configuration: `SA.RenderStack.ini`
- Legacy Bridge configuration path: `scripts/BridgeD3D9.ini`
- DXVK configuration: `dxvk.conf`
- SDK headers and Bridge symbols in their separate archives

## Backend

The backend is based on official DXVK `v3.0.1` and uses the audited SA
RenderStack GTA compatibility overlay. DXGI is merged into the D3D9 backend
for this x86 split profile; the separate DXGI target is disabled.

The supported deployment remains two DLLs. The single-DLL architecture is a
later experimental target and is not part of this alpha.

## Validation

The release is produced only from the reproducible x86 Release build and the
repository test gates. The generated split and source manifests are the
authoritative file and provenance records for each package.

## Changelog

- Added the first reproducible x86 split Bridge/DXVK package layout.
- Vendored official DXVK `v3.0.1` with the audited GTA SA compatibility overlay.
- Added API v7 ABI checks, export verification, runtime probes, and symbols.
- Added ordered proxy/plugin configuration metadata for later chain expansion.

## Compatibility

| Component | Supported baseline |
| --- | --- |
| Game | GTA San Andreas 1.0.0.0 US, 32-bit |
| Bridge | Win32 x86, MSVC Release |
| Backend | DXVK v3.0.1, LLVM-MinGW x86 |
| API | Backend API v7, Bridge plugin API v2 |
| DXGI | Merged into the D3D9 backend |
| ReShade/ENB | Optional external components; not bundled or validated |

## Rollback

Keep the existing audited split installation unchanged until the alpha has
passed the fixed game workload and soak test. The release package never writes
to the game directory. Restore the previous Bridge and backend files from the
existing installation or its separately preserved backup after stopping the
game and all loader processes.

## Known limitations

- This is an alpha baseline for controlled testing, not a drop-in replacement
  for every third-party D3D9 proxy.
- ReShade and ENB are optional external components and are not redistributed.
- No performance claim is made without the fixed-scene measurements described
  by the project validation plan.
