# SA RenderStack

SA RenderStack is a modular GTA San Andreas rendering runtime. The initial
release combines a root D3D9 proxy, ordered proxy/plugin hosting, GTA and
ProperShaders adapters, and a provenance-tracked DXVK Vulkan backend.

The supported baseline uses two DLLs. A single-DLL build is a later
experimental target and is not required for the initial release.

## Status

The repository is in modularization and release-preparation phase. Do not use
development artifacts as a public release without the generated manifest and
compatibility report.
